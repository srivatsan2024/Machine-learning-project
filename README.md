This is my R project. I worked on this project along with a group of 2 other people. With me included, 3 people worked on this project. We were supposed to take data
from QSAR biodegradation data set, which was created by Milano Chemometrics and QSAR Research Group. The data set is stored in biodeg.csv. As part of this project, we were supposed to generate questions in which we would solve. The questions we came up with are can we accurately predict whether a chemical compound is ready biodegradable based on its molecular structure? Which classification method best predicts biodegradability on held-out test data? Which molecular descriptors are most associated with a molecule being classified as ready biodegradable? And does the PCA structure of the data suggest why certain models outperform other models?
My part in this project was to generate and tune the model, and upon tuning, implement the models. I generated a Logistic Regression model, LDA model, Random forest, and a SVM model. The results of my process are detailed in the report that is attached to this git file.
